# Badcases

Create one directory or Markdown file per reproducible extraction failure. Use this template:

```markdown
# Badcase: <short name>

## Article excerpt
...

## Wrong output
...

## Expected output
...

## Failure class
hallucination | wrong_topic | wrong_subject | bad_evidence | over_split | positioning_inference

## Fix
Prompt | schema | rule change, with regression test reference.
```

Do not store cookies, tokens, authentication data, or private article content without permission.
